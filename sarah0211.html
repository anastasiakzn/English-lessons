    Reminder — when do we use the Present Continuous?

      Form: am / is / are + verb-ing

      Spelling: verb + ing

      RuleExamples
      Most verbs: + ingwork → working, read → reading, study → studying
      -e at the end: e → ingmake → making, write → writing, have → having
      short verb: vowel + consonant → doublesit → sitting, run → running, stop → stopping
      -ie → yinglie → lying, die → dying
