Warm-up: Idiom of the Day

To think outside the box
"To invent a solution, we must think outside the box."
Meaning: To think imaginatively using new ideas instead of traditional or expected ideas.
(Мыслить нестандартно, выходить за рамки привычного, мыслить креативно)

Practice: Mixed Conditionals

Grammar Theory

We use Mixed Conditionals when the time in the If-clause is not the same as the time in the Main clause. There are two main types:

Type If-clause (Condition) Main clause (Result)
Type 3 + 2
(Past action ➔ Present result)		 If + Past Perfect
(had + V3)		 would + V1
Example: If I had won the lottery last year, I would be rich now.
(Действие в прошлом повлияло на результат сейчас).
Type 2 + 3
(Present fact ➔ Past result)		 If + Past Simple
(V2 / ed)		 would have + V3
Example: If she knew French, she would have got the job in Paris yesterday.
(Постоянный факт в настоящем повлиял на ситуацию в прошлом).
